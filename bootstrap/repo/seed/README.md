# Cortex Foundry

Cortex Foundry is the research repository and persistent knowledge workspace for a research program designing a modular cognitive systems platform.

**Cortex Foundry is not the name of the future system being designed.** The system remains intentionally unnamed until research selects an appropriate canonical name.

## Purpose

This repository stores the canonical evolving state of the research program, including architecture, evidence, specifications, ontology, decisions, experiments, reference-workload analysis, and implementation handoff artifacts.

Chat transcripts are working context, not canonical project state.

## Workspace Philosophy

- evidence before familiarity;
- requirements before convenient technology;
- explicit contracts before hidden coupling;
- reusable modular composition before application forks;
- bounded files and progressive disclosure;
- durable repository state instead of chat-memory dependency.

The repository is intended to remain usable as a portable Git/Markdown knowledge base and may also be opened as an Obsidian Vault.
